WHAT IS WEEK 2?
═══════════════════════════════════════════════════════════════
Week 2 extends Week 1 baseline testing with:
  • LOAD TESTING: Multiple concurrent accounts, stress scenarios
  • STATE ANALYSIS: UTXO growth, accumulator compression efficiency

PURPOSE FOR DISSERTATION:
  • Show real-world throughput under concurrent load
  • Demonstrate state compression benefits
  • Identify network bottlenecks and capacity limits


PREREQUISITES
═══════════════════════════════════════════════════════════════
□ Anvil running:              npx anvil
□ Contracts deployed:         bash testing/run-week1.sh (first time)
□ .env configured with:       L2_RPC_URL, L2_OPERATOR_PRIVATE_KEY, PLASMA_CHAIN_UTXO_ADDRESS


RUN WEEK 2
═══════════════════════════════════════════════════════════════

SIMPLEST:
  bash testing/run-week2.sh

WITH CUSTOM LOAD:
  TEST_LOAD_ACCOUNTS=10 \
  TEST_LOAD_TX_PER_ACCOUNT=20 \
  TEST_CONCURRENCY=5 \
  bash testing/run-week2.sh

WITH STATE ANALYSIS OVER LARGE RANGE:
  STATE_ANALYSIS_START_BLOCK=0 \
  STATE_ANALYSIS_END_BLOCK=50000 \
  STATE_ANALYSIS_INTERVAL=100 \
  bash testing/run-week2.sh


WHAT HAPPENS
═══════════════════════════════════════════════════════════════

Phase 1: Load Testing (~30-60 seconds)
  1. Create 5 test accounts
  2. Fund them from operator account
  3. Execute 10 transfers per account (50 total)
  4. Measure: TPS, latency, success rate, gas
  
  Output: load-test-YYYY-MM-DD-HHmmss.json

Phase 2: State Analysis (~30-120 seconds, depends on block range)
  1. Sample blockchain state at intervals
  2. Track UTXO set size and accumulator
  3. Calculate compression ratio
  4. Analyze state growth patterns
  
  Output: state-growth-YYYY-MM-DD-HHmmss.json

TROUBLESHOOTING
═══════════════════════════════════════════════════════════════

❌ "Anvil not running"
   Solution: Start Anvil: npx anvil

❌ "Missing env var: L2_OPERATOR_PRIVATE_KEY"
   Solution: Check .env has all required variables

❌ "Load test shows 0% success"
   Solution: 
     1. Verify contracts deployed (run Week 1 first)
     2. Check operator has funds
     3. Verify PLASMA_CHAIN_UTXO_ADDRESS is correct

❌ "State analysis shows all zeros"
   Solution: Storage layout may differ from expectations
     - Check: cast storage $PLASMA_CHAIN_UTXO_ADDRESS
